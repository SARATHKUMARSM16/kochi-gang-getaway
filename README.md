# Kochi – The Gang Getaway (digital travel magazine)
```
npm install
npm run dev
```
- Edit trip info, places, coordinates and "last checked" date in `src/data.ts` only.
- Photos: drop JPGs into `public/img/` named `welcome.jpg, morning.jpg, fortkochi.jpg, watermetro.jpg, mattancherry.jpg, food.jpg, waterfront.jpg, homestay.jpg, night.jpg, wonderla.jpg, train.jpg, map.jpg`. Missing files show a gradient fallback. Use Unsplash / Wikimedia Commons and keep credits.
- Pins with `approx: true` must be confirmed in Google Maps before the trip.
